# Social assets

Rendered from the SVG marks in `public/brand`, at the sizes the platforms
actually want. The `.svg` sources are here too, so a size can be re-rendered
without redrawing anything.

| File | Where it goes |
| --- | --- |
| `x-avatar-dark-400.png` | X / profile picture, dark |
| `x-avatar-light-400.png` | X / profile picture, light |
| `x-avatar-brass-400.png` | Alternate, brass on ink |
| `x-header-1500x500.png` | X / header banner |
| `x-launch-card.png` | Launch post image, 16:9 so X does not crop it |
| `x-features-card.png` | Feature grid, for a follow-up post or a pinned tweet |
| `wordmark-*-1280.png` | Press, decks, anywhere needing the name as an image |
| `../generated/opengraph-card.png` | Link previews. **Generated by the site** |

## Two things that have already gone wrong once

**The OG card is generated at runtime** by `src/app/opengraph-image.tsx`. The
copy in `generated/` is a snapshot for convenience and it drifts: a stale one
with old copy was handed out for social use. If you need the file, pull it
fresh rather than trusting the checked-in copy:

```
curl -o opengraph-card.png https://sahn-ai.com/opengraph-image
```

**The header anchor star sits centre-right on purpose.** X overlays the
profile picture over the lower left, which covers anything placed there.
